# Benchmarking Accuracy and Bias on Encyclopedic Knowledge in (Vision-)Language Models

## MSc Maria Cassese, University of Pisa and ISTI-CNR, A. Y. 2025/26

This repository contains an implementation of the benchmark, prompting pipeline, and evaluation framework introduced in the paper **Benchmarking Accuracy and Bias on Encyclopedic Knowledge in (Vision-)Language Models**. The code supports experiments with both language and vision-language models and enables analysis of encyclopedic knowledge across geographic, demographic, multilingual, and online-presence dimensions.
